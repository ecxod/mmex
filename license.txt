Privacy Policy
================================================

This privacy-hardened fork does not collect or transmit application usage statistics.
People have different privacy concerns: our goal is to be clear about what information we collect, so that you can make meaningful choices about how it is used.

1. Using the MMEX application
The application contains no usage-statistics endpoint, persistent telemetry identifier, page-view tracking, or analytics code.

2. Network features
Update and news checks can contact the documented MMEX and GitHub services when enabled. Market-data refreshes contact the selected quote provider. These functional requests are not application-usage telemetry and can be disabled or avoided.

3. Third-party analytics
The installed application and bundled help do not load Google Analytics, advertising scripts, or remotely hosted JavaScript.

4. Usage statistics
Usage-statistics collection and transmission have been removed from this fork rather than merely disabled.

5. Your consent
By installing or using MMEX, you consent to this Privacy policy.

6. Changes to our Privacy policy
Any changes to this Privacy policy will correspond to an update to the date below.
